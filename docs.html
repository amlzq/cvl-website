概览

CVL（Chinese Variants Linter，中文变体检查器）检查简繁字形和地区用词是否与目标中文地区一致，并给出就地修改建议。

它适用于内容编辑、客服话术、表单填写和跨地区发布前的中文校对。检查在本机完成，网页文本、文档内容与词库不会上传到服务器。

四种目标地区用语：简体中文、中文（台湾）、中文（香港）、繁体中文。

快速开始

1. 选择平台

按你的工作环境安装浏览器扩展、Word 加载项或 macOS 菜单栏应用。当前安装 / 下载链接均指向各产品仓库，作为占位。

2. 设定目标地区

打开设置，选择目标中文地区用语与检测强度。浏览器扩展默认不对所有站点生效，需要时可开启「全站点默认开启检查」，或对当前站点单独设置。

3. 输入并确认

在编辑区输入、粘贴或选中文本。看到标记后，点击问题即可替换、忽略一次，或将词语加入允许词。

首次使用建议先确认目标地区：同一个词在不同地区的正确写法可能不同，例如「软件 / 軟體」「云端 / 雲端」。

浏览器扩展

适用于网页中的 textarea、文本 input 与 contenteditable 编辑区。

安装

Chrome 网上应用店链接暂指向仓库 · 占位 Microsoft Edge 加载项链接暂指向仓库 · 占位 Firefox 附加组件链接暂指向仓库 · 占位

使用

  • 打开扩展弹窗，选择目标地区用语和检测强度。
  • 在已启用检查的编辑区输入或粘贴文本，问题会以页面内标记和建议浮层显示。
  • 在复查面板中逐项替换、忽略一次，或加入允许词。
  • 选中文本后可单独转换，在可编辑区域中可将结果直接写回。

站点与快捷键

「全站点默认开启检查」默认关闭；开启后所有站点默认生效，其下方的站点开关可针对当前站点单独覆盖。检测开关、允许词组、自定义词组和快捷键都可在弹窗中配置。

扩展只声明 storage 与 activeTab 权限，设置与词库保存在浏览器本地存储中。

Office 加载项

CVL for Office 是一个 Word 加载项（任务窗格）：检查文档中混用的简体 / 繁体字形与两岸三地用词，逐条替换到目标写法。检查全部在本机完成，文档内容不会上传。

环境要求与试用

加载项需要 Word 桌面版或兼容环境。源码、构建步骤与试用方式见仓库中的 docs/BUILD.md。

使用

  • 在 Word 中打开任务窗格，选择目标地区用语。
  • 对文档执行检查，结果按条列出。
  • 逐条确认替换，或保留原文。

该项目为非官方实现，与 Microsoft 无关。功能范围与已知限制见仓库 docs/FEATURES.md。

macOS 应用

中文变体检查器的 macOS 版。常驻菜单栏，在任意应用的输入框中检查中文简繁字形和地区用词是否与目标地区一致，并提供就地替换。

安装

构建与安装说明见项目仓库；当前下载链接以仓库地址占位。

打开项目仓库（下载占位） →

使用

  • 在菜单栏中选择目标地区用语，在输入框中直接看到实时标记与建议浮窗。
  • 读不到文本的应用，可用全局快捷键检查或转换选中文本。
  • 默认跳过密码框，可按应用启用或禁用。
  • 允许词与自定义词组支持 CSV 和 OpenCC 词条格式导入导出。

文本只在本机处理，不联网、不上传。

词库与自定义

各平台都提供允许词与自定义词组，并按目标地区分开保存，避免一套词库影响所有地区。

允许词与自定义词组

  • 允许词：不希望被提示的词语，可逐条添加或在问题上直接加入。
  • 自定义词组：自己定义「原写法 → 目标写法」的对应关系，用于专有名词或行业术语。
  • 模板与清空：可下载模板、清空当前地区的词库。

CSV 格式

软件,軟體
云端,雲端
里面,裡面

OpenCC 词条格式

软件 軟體
云端 雲端
里面 裡面

导入前请先确认当前选择的目标地区，词条会写入对应地区的词库。建议定期导出备份。

常见问题

文本会被上传到服务器吗？

不会。浏览器扩展在本机处理网页文本，文档内容在 Word 本机检查，macOS 应用也不联网；设置和词库保存在本地。

支持哪些浏览器？

浏览器扩展提供 Chrome、Microsoft Edge 与 Firefox 版本，具体版本与安装方式见项目仓库。

可以检查哪些中文地区？

支持简体中文、中文（台湾）、中文（香港）和繁体中文四种目标地区用语。

某些词不想被提示怎么办？

可在问题上选择「忽略一次」，或把词语加入允许词。允许词按目标地区分开保存。

macOS 上读不到输入框文本怎么办？

部分应用不提供文本读取权限。此时可用全局快捷键对选中文本执行检查或转换。

如何备份自定义词库？

在设置中导出为 CSV 或 OpenCC 词条文件；需要时再按对应地区导入。
